# GARAJ — Ավտոմեքենաների առցանց շուկա Հայաստանում

**GARAJ** — онлайн-авторынок для Армении с мультивалютностью, проверкой VIN и историей аукционов США, системой торга и панелью модерации.

## Основные возможности
- **Каталог и умные фильтры**: поиск по регионам Армении, маркам, цене, году выпуска, статусу растаможки, состоянию и наличию VIN.
- **Мультивалютность**: автоматический пересчёт цен между `USD`, `AMD`, `EUR` и `RUB`.
- **Проверка VIN и аукционов США**: расшифровка заводских данных через NHTSA API + быстрые ссылки на Carfax, BidCars и Poctra.
- **Калькулятор растаможки и оформления**: ориентировочный расчёт пошлин и постановки на учёт в Армении (`AMD` / `USD`).
- **Торг («Առաջարկել իմ գինը»)**: покупатели могут предложить свою цену, а продавец принимает или отклоняет предложение в личном кабинете.
- **Прямая связь**: звонок в один клик (`tel:`), переход в WhatsApp, скрытие номера от парсеров и внутренние сообщения.
- **Тёмная и светлая тема**: переключение оформления сайта в настройках профиля.
- **Безопасность и модерация**: автосжатие фотографий перед загрузкой, нейросетевой фильтр 18+ контента (`NSFWJS`), фильтр ненормативной лексики (`HY / RU / EN`), бан пользователей, VIP-статусы и журнал действий администратора.

## Стек технологий
- **Frontend**: HTML5, CSS3, Vanilla JavaScript, TensorFlow.js (`NSFWJS`)
- **Backend**: PHP 8+, PDO
- **Database**: MySQL (`utf8mb4`)

## Локальный запуск (XAMPP)
1. Скопируйте папку проекта в `htdocs/garaj/`.
2. Запустите **Apache** и **MySQL** в панели XAMPP.
3. Откройте в браузере `http://localhost/garaj/` — база данных `garaj_db` и все таблицы создадутся автоматически через `includes/db.php`.
